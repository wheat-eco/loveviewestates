# **App Name**: Simple Hello

## Core Features:

- Text Display: Displays the text 'Hello' on the screen.

## Style Guidelines:

- Primary color: A calming blue (#64B5F6) to evoke simplicity and clarity.
- Background color: Very light blue (#E3F2FD), almost white, to keep focus on the message.
- Accent color: Soft lavender (#B39DDB), for any minimal UI elements.
- Body and headline font: 'Inter' (sans-serif) for a clean and readable display.
- Center the text 'Hello' on the screen for optimal visibility and balance.
